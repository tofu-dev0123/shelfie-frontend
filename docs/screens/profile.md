# ユーザープロフィール

## 概要

| 項目             | 内容                                                     |
| ---------------- | -------------------------------------------------------- |
| 画面名           | ユーザープロフィール                                     |
| 目的             | ユーザーのプロフィール情報と本棚を表示する               |
| URL パス         | `/users/:username`                                       |
| クエリパラメータ | なし                                                     |
| 認証             | 任意（認証状態によって表示内容が変わる）                 |

## UI要素

### プロフィールヘッダー

| 要素           | 種別   | 説明                                                               |
| -------------- | ------ | ------------------------------------------------------------------ |
| アバター画像   | Image  | ユーザーのアバター                                                 |
| ニックネーム   | Text   | 表示名                                                             |
| ユーザー名     | Text   | `@username` 形式                                                   |
| 自己紹介       | Text   | bio テキスト。未設定の場合は非表示                                 |
| 投稿数         | Text   | 読了本の投稿数                                                     |
| フォロワー数   | Link   | タップで `/users/:username/followers` へ遷移                       |
| フォロー中数   | Link   | タップで `/users/:username/following` へ遷移                       |
| フォローボタン | Button | `is_me: false` かつログイン済みのみ表示。未ログイン時は非表示      |
| 編集ボタン     | Button | `is_me: true` のときのみ表示。`/settings/profile` へ遷移          |

### 本棚エリア

| 要素               | 種別   | 説明                                                            |
| ------------------ | ------ | --------------------------------------------------------------- |
| タブ（読了）       | Tab    | 常に表示                                                        |
| タブ（読みたい）   | Tab    | `is_me: true` のときのみ表示                                    |
| 本カード           | Card   | グリッド表示。書影・タイトル・著者名を表示                      |
| 空状態メッセージ   | Text   | 本が0件のとき表示                                               |
| 本を投稿するボタン | Button | `is_me: true` かつ0件のとき表示。`/books/new` へ遷移           |

## インタラクション・動作フロー

### フォローボタン

1. ログイン済みユーザーが他人のプロフィールを開く
2. 「フォロー」ボタンをタップ
3. APIリクエスト送信中はボタンを disabled にする
4. 成功時：ボタンを「フォロー中」に変更、フォロワー数を更新
5. 失敗時：トースト通知を表示

### タブ切り替え

1. タブをタップすると対応する本棚に切り替える
2. 初期表示は「読了」タブ

### 無限スクロール

1. 初期表示で最大20件を取得して表示
2. スクロールが末尾に達したら次の20件を自動取得
3. 取得中はローディング表示
4. すべて取得済みの場合はローディングを非表示にする

## エラーハンドリング

| エラーケース                  | 対応                   |
| ----------------------------- | ---------------------- |
| 存在しないユーザー名          | `not-found.tsx` を表示 |
| プロフィール取得失敗（500系） | `error.tsx` を表示     |
| フォロー操作失敗              | トースト通知           |
| 本棚取得失敗                  | トースト通知           |

## 処理詳細

### プロフィール情報の取得

1. Server Component で `GET /v1/users/:username` を呼ぶ
2. レスポンスに含まれる `is_me` フラグをもとに表示を切り替える
   - ログイン済みリクエストの場合、バックエンドがアクセストークンから判定して `is_me` を返す
   - 未ログインリクエストの場合、`is_me: false` が返る
3. 存在しないユーザーの場合は `notFound()` を呼ぶ

### 本棚の取得

1. `GET /v1/users/:username/books?status=done&page=1` で読了本を取得（初期表示）
2. 無限スクロールで次ページを追加取得
3. 「読みたい」タブに切り替えたら `status=want` で同様に取得

### フォロー状態の取得

- `GET /v1/users/:username` のレスポンスにフォロー状態（`is_following: boolean`）を含める
- ログイン済みリクエストの場合のみバックエンドが判定して返す
- 未ログインの場合は `is_following: false`

## 関連画面・遷移先

| 遷移先                                    | 条件                             |
| ----------------------------------------- | -------------------------------- |
| `/settings/profile`                       | 編集ボタンタップ（自分のページ） |

| `/users/:username/followers`              | フォロワー数タップ               |
| `/users/:username/following`              | フォロー中数タップ               |
| `/users/:username/books/:google_books_id` | 本カードタップ                   |
