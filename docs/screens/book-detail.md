# 本棚投稿詳細

## 概要

| 項目             | 内容                                                                |
| ---------------- | ------------------------------------------------------------------- |
| 画面名           | 本棚投稿詳細                                                        |
| 目的             | 特定ユーザーの本棚に登録された1投稿（本＋コメント＋タグ）を表示する |
| URL パス         | `/users/:username/books/:isbn`                                      |
| クエリパラメータ | なし                                                                |
| 認証             | 任意（認証状態によって表示・アクションが変わる）                    |

## UI要素

### 書籍情報エリア

| 要素     | 種別  | 説明                                                       |
| -------- | ----- | ---------------------------------------------------------- |
| 書影     | Image | `book.thumbnail_url` を表示。null のときはプレースホルダー |
| タイトル | Text  | `book.title`                                               |
| 著者     | Text  | `book.authors` を半角スペース区切りで結合                  |
| ISBN     | Text  | `book.isbn` を補助情報として小さく表示                     |

### 投稿者エリア

| 要素              | 種別   | 説明                                                                 |
| ----------------- | ------ | -------------------------------------------------------------------- |
| アバター          | Image  | `user.avatar_url` を表示。null のときはプレースホルダー              |
| ニックネーム      | Text   | `user.nickname`                                                      |
| ユーザー名        | Text   | `@user.username` 形式                                                |
| 投稿日時          | Text   | `created_at` を `YYYY-MM-DD` 形式で表示（`updated_at` は使用しない） |
| 3点リーダーボタン | Button | 常に表示。タップでドロップダウンメニューを開閉                       |

### 3点リーダー ドロップダウンメニュー

| 要素    | 種別   | 表示条件                                           | 説明                                              |
| ------- | ------ | -------------------------------------------------- | ------------------------------------------------- |
| 編集    | Button | 自分の投稿（`user.username === ログインユーザー`） | アイコン付き。投稿編集画面へ遷移                  |
| 共有    | Button | 常時                                               | アイコン付き。現ページURLをクリップボードへコピー |
| Xへ共有 | Button | 常時                                               | アイコン付き。X投稿URLを新規タブで開く            |

### タグ

| 要素       | 種別 | 説明                                                          |
| ---------- | ---- | ------------------------------------------------------------- |
| タグチップ | Chip | `tags[]` を `#タグ名` 形式で列挙。MVPでは遷移なし（表示のみ） |

### コメント本文

| 要素         | 種別 | 説明                                                                                                                                                        |
| ------------ | ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| コメント本文 | Text | `content` を表示。改行を保持（`white-space: pre-wrap`）。本文中のURLを自動リンク化（新規タブで開く）。本文中の `#ハッシュタグ` をハイライト表示（遷移なし） |

### 購入リンクエリア

| 要素       | 種別 | 説明                                                                                                                                              |
| ---------- | ---- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| 購入リンク | Link | `purchase_links[]` を列挙。Amazon / 楽天ブックスに該当するドメインはURL左横にラベルを表示。それ以外はURLのみ。空配列の場合はセクション自体を非表示 |

### 読みたいリストに追加ボタン

| 要素                       | 種別   | 表示条件                       | 説明                                                                                     |
| -------------------------- | ------ | ------------------------------ | ---------------------------------------------------------------------------------------- |
| 読みたいリストに追加ボタン | Button | 自分の投稿ではない場合のみ表示 | コンテンツ下部（購入リンクの下）に配置。タップで `POST /v1/me/want_to_reads/:isbn` を送信 |

## インタラクション・動作フロー

### 3点リーダーメニューの開閉

1. 投稿者エリア右側の3点リーダーボタンをタップ → メニュー展開
2. 外側タップ / Esc キー → メニューを閉じる

### 共有（URLコピー）

1. 3点リーダーメニューの「共有」をタップ
2. 現ページのURLをクリップボードにコピー
3. 成功時、トースト「URLをコピーしました」

### Xへ共有

1. 3点リーダーメニューの「Xへ共有」をタップ
2. 書籍タイトル + 現ページURLを含むX投稿用URLを生成し、新規タブで開く

### 編集

1. 3点リーダーメニューの「編集」をタップ（自分の投稿のみ表示）
2. 投稿編集画面へ遷移（削除アクションは編集画面側で実施）

### 読みたいリストに追加

- ログイン済み
    1. ボタンタップ中は disabled
    2. `POST /v1/me/want_to_reads/:isbn` を送信
    3. 成功 → 成功トースト
    4. 409 Conflict → トースト「すでに追加済みです」
    5. その他失敗 → エラートースト
- 未ログイン
    1. ボタンタップ
    2. ログインを促すトーストを表示
    3. ログイン画面へ遷移

## エラーハンドリング

| エラーケース                                                    | 対応                                             |
| --------------------------------------------------------------- | ------------------------------------------------ |
| 投稿が存在しない（404。ユーザー不存在・書籍不存在・投稿不存在） | `not-found.tsx` を表示（ホームへのリンクを配置） |
| 投稿詳細取得失敗（500系）                                       | `error.tsx` を表示                               |
| 読みたいリスト追加失敗                                          | トースト                                         |
| 読みたいリスト409（追加済み）                                   | トースト「すでに追加済みです」                   |
| URLコピー失敗（Clipboard API 非対応等）                         | トースト                                         |

## 処理詳細

### 投稿詳細の取得

1. Server Component で `GET /v1/users/:username/books/:isbn` を呼ぶ
2. 404 なら `notFound()` を呼ぶ
3. レスポンスを詳細コンポーネントに渡して描画
4. 初期表示のロード中は `loading.tsx` のスケルトンUIを表示

### 自分/他人の判定

- ログイン中ユーザーの username と URLパラメータの `:username` が一致するかで判定
- 一致 → 「読みたいリスト追加ボタン」を非表示、3点リーダー内「編集」を表示
- 不一致 または 未ログイン → 「読みたいリスト追加ボタン」を表示、3点リーダー内「編集」を非表示

### 購入リンクのラベル判定

1. 各URLのドメインを抽出
2. `amazon.` を含む → 「Amazon」ラベルを添えて表示
3. `rakuten.` / `books.rakuten.` を含む → 「楽天ブックス」ラベルを添えて表示
4. 上記以外 → ラベルなし（URLのみ表示）

### コメント本文の装飾

1. 改行は `white-space: pre-wrap` で保持
2. 本文中のURLを正規表現で検出 → `<a target="_blank" rel="noopener noreferrer">` で囲う
3. 本文中の `#タグ名` を正規表現で検出 → ハイライトスタイルを適用（遷移はしない）
