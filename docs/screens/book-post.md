# 本の投稿

## 概要

| 項目             | 内容                   |
| ---------------- | ---------------------- |
| 画面名           | 本の投稿               |
| 目的             | 読了した本を投稿する   |
| URL パス         | `/books/new`           |
| クエリパラメータ | なし                   |
| 認証             | 必須                   |

## UI要素

### 本の選択エリア（未選択時）

| 要素         | 種別   | 説明                                                       |
| ------------ | ------ | ---------------------------------------------------------- |
| 本の検索入力 | Input  | テキスト入力欄。入力のたびに書籍検索 API を呼ぶ           |
| 検索結果リスト | List | 書影・タイトル・著者名を表示。クリックで本を選択する      |

### 本の選択エリア（選択済み時）

| 要素         | 種別   | 説明                                                       |
| ------------ | ------ | ---------------------------------------------------------- |
| 選択済み本   | Card   | 書影・タイトル・著者名を表示                               |
| 変更するリンク | Link | クリックで選択を解除し、未選択状態に戻る                  |

### 投稿フォーム（本を選択後に表示）

| 要素           | 種別         | 説明                                                                |
| -------------- | ------------ | ------------------------------------------------------------------- |
| コメント入力   | Textarea     | 必須。最大1000文字                                                  |
| タグ絞り込み入力 | Input      | テキスト入力でタグ候補を絞り込む                                    |
| タグ候補リスト | Checkbox list | バックエンドのシードデータ一覧。チェックで選択・解除               |
| 選択済みタグ   | Badge        | 選択中のタグをバッジ表示。✕ボタンで個別解除できる                  |
| タグ上限警告   | Text         | 6個以上選択した時点で「タグは5個までです」を表示                    |
| 投稿ボタン     | Button       | 送信。`isSubmitting` 中は disabled                                  |

## インタラクション・動作フロー

### 本の選択

1. ユーザーが検索入力欄にキーワードを入力する
2. 書籍検索 API にリクエストを送信し、結果リストを表示する
3. ユーザーが結果リストから本をクリックして選択する
4. 検索エリアが折りたたまれ、選択済み本のカードが表示される
5. 投稿フォームが出現する

### 本の変更

1. ユーザーが「変更する」リンクをクリックする
2. 選択済み本と投稿フォームが非表示になる
3. 検索エリアが再展開され、未選択状態に戻る

### タグの選択

1. ユーザーがタグ絞り込み入力欄にテキストを入力する（任意）
2. テキストに部分一致するタグ候補のみに絞り込まれる
3. チェックボックスをクリックしてタグを選択する
4. 選択済みタグがバッジとして表示される
5. 6個以上選択した場合、「タグは5個までです」の警告を表示する

### 投稿

1. ユーザーが投稿ボタンをクリックする
2. バリデーションを実行する（下記「バリデーション」参照）
3. バリデーション通過後、書籍投稿 API にリクエストを送信する
4. 成功時: トースト通知を表示し、投稿した本の持ち主のプロフィール画面へ遷移する
5. 失敗時: トースト通知を表示する

## バリデーション

| フィールド | ルール                   | エラーメッセージ                 |
| ---------- | ------------------------ | -------------------------------- |
| 本         | 必須（未選択は投稿不可） | 本を選択してください             |
| コメント   | 必須・最大1000文字       | コメントは必須です               |
|            |                          | 1000文字以内で入力してください   |
| タグ       | 任意・最大5個            | タグは5個以内で選択してください  |

## エラーハンドリング

| エラーケース               | 対応         |
| -------------------------- | ------------ |
| 書籍検索 API 失敗（500系） | トースト通知 |
| 書籍投稿 API 失敗（500系） | トースト通知 |
| タグ取得 API 失敗（500系） | トースト通知 |

## 処理詳細

### 書籍検索

1. ユーザーが検索入力欄に入力する
2. `GET /v1/books/search?q=キーワード` にリクエスト
3. レスポンスの書籍一覧を結果リストに表示する
4. 結果が0件の場合は空状態メッセージを表示する

### タグ取得

1. ページロード時に `GET /v1/tags` にリクエストを送信する
2. 取得したタグ一覧をチェックボックスリストに表示する

### 書籍投稿

1. ユーザーが投稿ボタンをクリックする
2. Zodバリデーションを実行する
3. `POST /v1/books` に以下のデータを送信する
   - `isbn`: 選択した本のISBN
   - `content`: コメント
   - `tags`: 選択済みタグの配列
4. 成功時: トースト通知（「投稿しました」）を表示し、自分のプロフィール画面へ遷移する
