# 検索

## 概要

| 項目             | 内容                                     |
| ---------------- | ---------------------------------------- |
| 画面名           | 検索                                     |
| 目的             | キーワードで本を検索する                 |
| URL パス         | `/search`                                |
| クエリパラメータ | `q`（検索キーワード）                    |
| 認証             | 必須                                     |

> **ペンディング**: ユーザー検索はAPIが未設計のため未実装。将来的にタブで切り替える形で追加予定。

## UI要素

### 検索フォーム

| 要素           | 種別   | 説明                                             |
| -------------- | ------ | ------------------------------------------------ |
| キーワード入力 | Input  | テキスト入力欄。プレースホルダー: 「本を検索」   |
| 検索ボタン     | Button | 送信ボタン。クリックで検索を実行する             |

### 検索結果

| 要素             | 種別 | 説明                                                                                       |
| ---------------- | ---- | ------------------------------------------------------------------------------------------ |
| 書籍カード       | Card | 書影・タイトル・著者名・出版年を表示。クリックで `/books/:google_books_id` へ遷移           |
| 空状態メッセージ | Text | 検索結果が0件のとき表示                                                                    |
| 未検索メッセージ | Text | 初期表示（未検索）のとき表示                                                               |

## インタラクション・動作フロー

### 検索実行

1. ユーザーがキーワードを入力して検索ボタンをクリック
2. クエリパラメータ `q` に入力値をセットして URL を更新（`/search?q=キーワード`）
3. 書籍検索 API にリクエストを送信する
4. 検索中はボタンを disabled にしてローディング表示
5. 結果を一覧表示する

### ページロード時の復元

1. URL に `q` がある場合、入力欄に値をセットする
2. `q` がある場合はページロード時に自動で検索を実行する

## エラーハンドリング

| エラーケース               | 対応         |
| -------------------------- | ------------ |
| 書籍検索 API 失敗（500系） | トースト通知 |

## 処理詳細

### 書籍検索

1. ユーザーが検索ボタンを押す
2. `GET /v1/books/search?q=キーワード` にリクエスト（アクセストークンを付与）
3. レスポンスの書籍一覧をカード形式で表示する
4. 結果が0件の場合は空状態メッセージを表示する

## 関連画面・遷移先

| 遷移先                    | 条件                   |
| ------------------------- | ---------------------- |
| `/books/:google_books_id` | 書籍カードをクリック   |
