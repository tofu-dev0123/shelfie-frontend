# review スキル

Shelfieプロジェクトのコードを総合的にレビューする。

## フロー

### ステップ1: スコープ確認

ユーザーから調査対象のスコープを確認する。

- **指定なし**: `src/` 配下全体を対象
- **特定ディレクトリ指定**: そのディレクトリのみ対象
- **特定チェックのみ指定**: 該当するエージェントのみ起動

### ステップ2: サブエージェントを並列起動

以下の5つのエージェントを**1つのメッセージで同時に**起動する。

| エージェント | 役割 |
|---|---|
| `guideline-checker` | ガイドライン違反チェック |
| `lint-checker` | ESLintによるリントチェック |
| `type-checker` | TypeScript型チェック |
| `format-checker` | Prettierフォーマットチェック |
| `test-runner` | Vitestテスト実行 |

各エージェントに対してAgentツールを使い、単一メッセージ内で全て並列呼び出しすること。

### ステップ3: 統合レポートの出力

全エージェントの結果を収集し、以下の形式でまとめて報告する。

```
## レビュー結果

| チェック           | 結果           |
|-------------------|---------------|
| ガイドライン        | ✅ / ⚠️ X件違反 |
| リント             | ✅ / ❌ X件    |
| 型チェック          | ✅ / ❌ X件    |
| フォーマット         | ✅ / ❌ X件    |
| テスト             | ✅ / ❌ X件失敗 |

---

## ガイドライン
（guideline-checker の出力をそのまま掲載）

## リント
（lint-checker の出力をそのまま掲載）

## 型チェック
（type-checker の出力をそのまま掲載）

## フォーマット
（format-checker の出力をそのまま掲載）

## テスト
（test-runner の出力をそのまま掲載）
```

問題がある場合は、型エラー・テスト失敗を優先して先に記載する。
