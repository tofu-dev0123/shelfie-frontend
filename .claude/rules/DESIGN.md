# デザインシステム

## デザイン基本原則

### Contrast（コントラスト）
異なるものは明確に異なって見せる。

- テキストの階層（見出し・本文・補足）はサイズ・ウェイトで明確に差をつける
- プライマリボタンとセカンダリボタンは一目で区別できるようにする
- アクティブな状態・非アクティブな状態をコントラストで示す
- 書影と背景のコントラストを確保し、本の表紙が際立つようにする

### Repetition（反復）
色・フォント・形・余白を繰り返して統一感を出す。

- ブランドカラー・フォント・角丸・スペーシングは必ずデザイントークンから使用する
- カード・バッジ・ボタンなどのUIパターンはアプリ全体で一貫して使い回す
- アイコンスタイル・ボーダースタイルを混在させない

### Alignment（整列）
すべての要素を意図的に揃える。

- 要素は左端・グリッドラインに揃える（中央揃えは見出しなど限定的な場面のみ）
- カード内のテキスト・画像は統一したパディングで揃える
- フォームのラベル・入力欄は垂直方向に整列させる

### Proximity（近接）
関連する要素は近くにまとめ、無関係な要素とは距離を置く。

- 本のタイトルと著者名は近くに置き、ひとつの情報グループとして扱う
- アクションボタンは対象コンテンツの近くに配置する
- セクション間の余白はセクション内の要素間より大きくする

## カラー

### ブランドカラー

ベース: `#1E3A5F`（ディープネイビー）

| トークン | 用途 |
|---|---|
| `--color-primary-50` | 薄い背景・ホバー背景 |
| `--color-primary-100` | セカンダリボタン背景 |
| `--color-primary-200` | ボーダー・区切り |
| `--color-primary-600` | プライマリボタン・リンク・アクセント（メインカラー） |
| `--color-primary-700` | ホバー時 |
| `--color-primary-900` | 強調テキスト |

### グレースケール

| トークン | 値 | 用途 |
|---|---|---|
| `--color-gray-50`  | `#F9FAFB` | ページ背景 |
| `--color-gray-100` | `#F3F4F6` | カード内背景・画像プレースホルダー |
| `--color-gray-200` | `#E5E7EB` | ボーダー・区切り線 |
| `--color-gray-300` | `#D1D5DB` | 非アクティブボーダー |
| `--color-gray-400` | `#9CA3AF` | プレースホルダーテキスト |
| `--color-gray-500` | `#6B7280` | 補足テキスト・ラベル |
| `--color-gray-600` | `#4B5563` | セカンダリテキスト |
| `--color-gray-700` | `#374151` | 本文テキスト |
| `--color-gray-900` | `#111827` | 見出し・プライマリテキスト |

### セマンティックカラー

| トークン | 値 | 用途 |
|---|---|---|
| `--color-success` | `#059669` | 成功・読了バッジ |
| `--color-warning` | `#D97706` | 警告・読書中バッジ |
| `--color-error`   | `#DC2626` | エラー・削除 |

## タイポグラフィ

### フォントファミリー

```css
--font-sans: 'Inter', sans-serif;
```

### フォントサイズスケール

| トークン | 値 | 用途 |
|---|---|---|
| `--text-xs`   | `11px` | ラベル・キャプション（uppercase） |
| `--text-sm`   | `13px` | 補足テキスト・著者名 |
| `--text-base` | `15px` | 本文 |
| `--text-lg`   | `18px` | セクション見出し（h3） |
| `--text-xl`   | `24px` | ページ内見出し（h2） |
| `--text-2xl`  | `32px` | ページタイトル（h1） |

### フォントウェイト

| トークン | 値 | 用途 |
|---|---|---|
| `--font-normal`    | `400` | 本文 |
| `--font-medium`    | `500` | ボタン・ナビリンク |
| `--font-semibold`  | `600` | カードタイトル・h3 |
| `--font-bold`      | `700` | h2・統計数値 |
| `--font-extrabold` | `800` | h1・ロゴ |

### 行間

```css
--leading-tight:  1.4;   /* 見出し */
--leading-normal: 1.6;   /* UI テキスト */
--leading-relaxed: 1.7;  /* 本文・説明文 */
```

| `--space-6`  | `24px` | セクション内余白 |
| `--space-8`  | `32px` | カードパディング |
| `--space-10` | `40px` | セクションパディング（横） |
| `--space-12` | `48px` | セクションパディング（縦） |

## シャドウ

フラットデザインを採用。影は使用しない。カードの区切りはボーダーのみで表現する。

```css
--shadow-none: none;

/* ホバー時のみ、控えめな影を許容する */
--shadow-hover: 0 4px 16px rgba(0, 0, 0, 0.08);
```

## ブレークポイント

モバイルファーストで記述する。

| トークン | 値 | 対象 |
|---|---|---|
| `sm` | `640px`  | スマホ横・小型タブレット |
| `md` | `768px`  | タブレット |
| `lg` | `1024px` | PC |

```css
/* 使用例 */
.container {
  padding: var(--space-4);
}

@media (min-width: 768px) {
  .container {
    padding: var(--space-10);
  }
}
```
