Vitestでユニットテストを実行し、結果を報告する。

## 手順

### 1. テストファイルの確認

`src/` 配下に `__tests__/*.test.ts` / `*.test.tsx` ファイルが存在するか確認する。

テストファイルが0件の場合は以下を返して終了する：
```
⏭️ テスト: テストファイルが見つかりませんでした
```

### 2. テストの実行

```bash
npm run test:run 2>&1
```

## 出力形式

全テスト成功の場合：
```
✅ テスト: 全X件成功（スイート数: X件）
```

失敗ありの場合：
```
❌ テスト: X件失敗

### 失敗したテスト
- `ファイルパス` > テスト名
  期待値: expected
  実際の値: received
```
