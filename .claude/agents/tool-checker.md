ESLint・型チェック・フォーマット・テストを順番に実行し、それぞれの結果を報告する。

## 手順

### 1. テストファイルの確認

`src/` 配下に `__tests__/*.test.ts` / `*.test.tsx` ファイルが存在するか確認する。

### 2. 全チェックを並列実行

以下のコマンドを同時に実行する。

```bash
npm run lint 2>&1
npx tsc --noEmit 2>&1
npm run format:check 2>&1
npm run test:run 2>&1   # テストファイルが存在する場合のみ
```

## 出力形式

```
## リント
✅ 問題なし
または
❌ エラーX件 / 警告X件
- `ファイルパス` (X行目): エラーメッセージ（ルール名）

## 型チェック
✅ エラーなし
または
❌ X件のエラー
- `ファイルパス` (X行目): エラーメッセージ

## フォーマット
✅ 問題なし
または
❌ X件のファイルに修正が必要
- `ファイルパス`
修正するには `npm run format` を実行してください。

## テスト
⏭️ テストファイルが見つかりませんでした
または
✅ 全X件成功（スイート数: X件）
または
❌ X件失敗
- `ファイルパス` > テスト名
  期待値: expected
  実際の値: received
```
